# Simply-Blocks-Revamped-Chrome-Chrome-Extension

## About Simply Blocks

Simply Blocks is a Chrome productivity extension that combines a customizable New Tab page, browser side panel, visual block workspace, document editor, Google Workspace integration, and AI-powered Markdown workflows.

## Main Features

- Replaces Chrome’s New Tab page with a customizable productivity dashboard.
- Provides a side panel that can be opened while browsing.
- Supports fullscreen browsing with fullscreen and side-panel controls.
- Includes customizable website shortcuts.
- Lets users customize background, glow, and text-gradient colors.
- Includes optional Simply Blocks styling for supported websites.
- Provides adjustable automatic page scrolling.
- Supports Google Account sign-in and profile management.

## Visual Block Workspace

The Block Workspace lets users create reusable browser and file-processing workflows visually.

Users can:

- Create blocks for websites and AI services.
- Give blocks custom names, URLs, and colors.
- Move blocks around the canvas.
- Connect blocks to define an execution order.
- Edit or delete existing blocks.
- Open block URLs in a dedicated Chrome tab group.
- Pause and resume active Markdown file flows.
- Reuse the same block configuration with new Markdown files.
